# Getting started

Use this guide when you are opening Opslora for the first time or setting up a new organization workspace.

## Open the application

Production app:

```text
https://app.opslora.com
```

Test app:

```text
https://app-test.opslora.com
```

Use the test app when validating demo data or checking a feature before relying on it in production.

## Create an organization

1. Open the signup page.
2. Enter the organization name.
3. Confirm or adjust the organization slug.
4. Enter the first admin user's email and password.
5. Submit the form.

The first user becomes the owner/admin for that organization.

## Sign in

1. Open the login page.
2. Enter the organization slug.
3. Enter your email and password.
4. After login, Opslora opens the dashboard.

If you are already signed in, the login page redirects you to the dashboard.

## First setup checklist

After signing in, complete these steps before running real workflows:

- Add or verify the business profile in Settings.
- Add tax profile details if invoices need tax information.
- Review invoice defaults and invoice templates.
- Add at least one customer.
- Add sellable products and stock balances.
- Create a test order.
- Confirm the order.
- Create an invoice from the confirmed order.
- Record a test payment.

## Main navigation

The left navigation currently includes:

- Dashboard
- Customers
- Inventory
- Orders
- Invoices
- Payments
- Lora AI
- Settings

Settings also includes:

- Business profile
- Tax profile
- Invoice defaults
- Feature flags
- Portal
- Lora AI consent
- Profile settings
- Invoice templates

## Good demo path

For a clean demo, use this sequence:

1. Create a customer.
2. Add a product and stock.
3. Create an order for that customer.
4. Confirm the order.
5. Create an invoice from the order.
6. Record a payment.
7. Review dashboard totals.
8. If Lora AI is enabled, ask it to summarize open invoices or orders ready to invoice.
